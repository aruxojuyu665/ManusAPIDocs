# Repository Structure

This document outlines the directory structure of the Manus API Documentation repository.

```
ManusAPIDocs/
├── getting-started/          # Getting started guides
│   ├── overview.md           # Introduction to Manus API v2
│   ├── authentication.md     # Authentication guide
│   ├── task-lifecycle.md     # Task lifecycle guide
│   ├── agents.md             # Agents guide
│   ├── website.md            # Website guide
│   └── rate-limits.md        # Rate limits guide
├── webhooks/                 # Webhooks documentation
│   ├── overview.md           # Webhooks overview
│   └── security.md           # Webhook security guide
├── api-reference/            # API endpoints reference
│   ├── tasks/                # Task management endpoints
│   ├── projects/             # Project management endpoints
│   ├── skills/               # Skill management endpoints
│   ├── agents/               # Agent management endpoints
│   ├── files/                # File management endpoints
│   ├── webhooks/             # Webhook management endpoints
│   ├── usage/                # Usage statistics endpoints
│   ├── connectors/           # Connector management endpoints
│   ├── browser/              # Browser management endpoints
│   └── website/              # Website management endpoints
├── connectors/               # Connectors documentation
│   └── overview.md           # Connectors overview
├── integrations/             # Integrations documentation
│   ├── overview.md           # Integrations overview
│   └── slack.md              # Slack integration guide
└── data-integrations/        # Data Integrations documentation
    ├── overview.md           # Data Integrations overview
    └── similarweb.md         # Similarweb integration guide
```
